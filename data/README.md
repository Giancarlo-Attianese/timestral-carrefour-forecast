# Data / Dati

**EN** — Download the dataset from Kaggle and save it here as `Carrefour.csv`:
[Carrefour Online Sales](https://www.kaggle.com/datasets/sherifhesham89/carrefour-online-sales). The raw file is not in the repository; the aggregated daily series used by the analysis are in `results/series.csv`. The CSV is encoded in Windows-1252, and the scripts read it that way.
